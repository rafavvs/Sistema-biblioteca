Sistema de Biblioteca

Projeto acadêmico para demonstrar o padrão MVC com Spring MVC e Thymeleaf.

Como o MVC funciona neste projeto

  1. Requisição: o navegador acessa uma rota, como /livros.
  2. Controller: recebe a requisição, executa a ação e seleciona uma página. Por exemplo, LivroController.
  3. Model: os objetos Livro, Autor e os demais representam os dados. O controller os disponibiliza para a página usando o Model do Spring.
  4. View: o Thymeleaf combina a página HTML com os dados e devolve o resultado ao navegador.

Exemplo: GET /livros → LivroController → dados dos livros → templates/livros/inicio.html.

Os cadastros deste projeto ficam em listas na memória e não são mantidos após reiniciar a aplicação.
